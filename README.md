# Очереди для Telegram

Бот публикует карточки очередей в группах и темах, открывает и закрывает запись по расписанию. В каждой группе одновременно может быть до 10 запланированных и открытых очередей. После закрытия очередь освобождает место для новой.

## Запуск

1. Создайте бота командой `/newbot` в [@BotFather](https://t.me/BotFather). Если добавление в группы отключено, включите его командой `/setjoingroups`.
2. Запустите Docker Desktop. В PowerShell из папки проекта выполните `Copy-Item .env.example .env` и впишите токен в `BOT_TOKEN` в файле `.env`. По умолчанию бот использует московское время. При необходимости укажите другой часовой пояс IANA в `BOT_TIMEZONE`.
3. Запустите контейнер.

   ```powershell
   docker compose up -d --build
   docker compose logs -f bot
   ```

4. Добавьте бота в группу и убедитесь, что он может отправлять сообщения. Управляющие команды выполняют администраторы группы. Если Telegram не передаёт боту команду, адресуйте её явно, например `/queuehelp@ИмяВашегоБота`.

Бот получает обновления через long polling. Запускайте один экземпляр на каждый токен. Очереди и записи хранятся в томе `telegram-queues_queues`. `docker compose down` сохраняет этот том, а `docker compose down -v` удаляет его вместе с данными.

## Управление очередями

Отправьте `/queue` в группе или теме и нажмите «Создать очередь». Бот откроет пошаговую настройку в личном чате. Введите название, затем отдельно задайте дату и время открытия и закрытия. Для даты есть кнопки «Сегодня», «Завтра» и «Другая дата». Введите время в формате `ЧЧ:ММ` или нажмите «Назад», чтобы снова выбрать дату. В конце нажмите «Опубликовать».

Очередь также можно создать одной командой, подставив свои даты.

```text
/queue Методология программирования 25.11.26 | 24.11.2026 18:00 | 25.11.2026 11:45
```

Бот публикует карточку в том же чате или теме. Если время открытия уже прошло, а закрытие ещё впереди, запись открывается сразу.

- `/queues` показывает запланированные и открытые очереди с номерами.
- `/closequeue 3` досрочно закрывает очередь №3 в текущей группе.
- `/refreshqueue`, отправленная ответом на карточку очереди, публикует обновлённую карточку в той же теме. Номер, расписание и участники сохраняются.
- `/queuehelp` показывает подсказку.

## Запись студентов

1. До открытия «Занять очередь» неактивна. Когда запись открывается, кнопка становится синей и доступной. Один аккаунт может записаться в каждую очередь один раз. Бот сообщает номер места.
2. В личном подтверждении внутри группы доступны красная кнопка «Отменить запись» и нейтральная «Посмотреть очередь». Те же действия доступны в общей карточке. При нажатии «Посмотреть очередь» бот показывает полный список, а для длинной очереди присылает текстовый файл.
3. После отмены номера пересчитываются. При повторной записи студент занимает последнее место. После закрытия можно просматривать список и отменять свою запись.

Карточки и личные подтверждения используют [Rich Messages](https://core.telegram.org/bots/api#rich-html-style). Для отображения кнопок нужен клиент Telegram с поддержкой этого формата.
